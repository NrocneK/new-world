# Air jump — anime side profile v1

Eight cels, 4 × 2, 384 × 640 per cel, transparent PNG. This is a separate vertical boost while already airborne: tuck, coil, push downward, rise, apex and descent into the common landing. It keeps current horizontal momentum.

Generated source: `air-jump-source.png`, copied unchanged from `generated_images/exec-00cf7b08-7572-40f8-be3e-32ef6276843f.png`, referencing the new jump source and approved walk identity. It shares jump's single whole-figure packing scale and head/floor references. Cel 0 reuses jump's apex (cel 4) for a clean transition; cel 2 reuses jump's full extension (cel 2) to keep the push pose's body/leg lengths identical. Remaining cels are complete generated drawings, without limb assembly or warps.

The independent 900 ms preview starts 100 stage pixels above the floor and ends in a falling pose. In interactive play, collision with the floor switches to the common jump landing/recovery. Normal/slow GIFs, PNG atlas, metadata, individual cels and inspection stills are included. Build and audit instructions are in `../anime-jump-profile-v1/README.md`.
